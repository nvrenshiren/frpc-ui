# 原型验证记录

日期：2026-10-08。范围：浏览器中的 React 前端与模拟领域状态，不包含 Rust、真实 frpc 或安装包。

## 已通过

- 严格 TypeScript 检查和 Vite 生产构建。
- 批量作用域：筛选上海连接后，全选只选择其 3 条隧道；停用后配置标待应用，应用后清除标记。
- 部分失败：批量启动 4 个连接得到 3 成功、1 失败；失败节点显示进程运行但连接异常，重试启动成功。重试只重复原操作。
- 条件表单：创建连接；HTTPS 转 HTTP 缺域名与证书路径时拒绝保存；TCP 同长度端口范围保存并在列表呈现。
- 配置转换：TOML 导出、解析预览、新增连接；已有管理端口自动避让。范围导出为独立代理；提供者、访客、IPv6 目标及证书路径往返通过。
- 不支持字段、非法 TOML、无效端口、缺失访客提供者名称与证书路径明确拒绝。
- 凭据默认从导出与分享中移除，勾选后才包含；Unicode 分享往返通过，停用隧道在 TOML 导出时排除、分享时保留。
- 版本占用保护：正在被配置使用的版本不能卸载；可模拟安装未安装版本。
- 日志按连接与级别筛选，暂停冻结快照；复制内容与当前筛选一致，文本文件实际下载成功。日志按文本节点呈现，缓存上限 200 条。
- 亮暗主题、中英文切换立即生效。配置与凭据不进入 localStorage；仅导航与界面偏好持久化。
- 1440、实际 1280 和 390 宽度检查。390 时页面无横向溢出，密集表格在自身容器中水平滚动。
- 浏览器检查过程中未记录 console error 或 warn；机械设计检测无发现。

主机/IP/名称/端口校验、异步应用时再次编辑的修订保护、停止后保留待应用，以及有界缓存已通过实际实现函数的临时行为检查。未为实现镜像添加低价值永久测试文件。

## 必须后续验证

真实连接和各协议配置须经过 `frpc verify` 与受控 frps 联调；进程退出回收、并发监督、动态版本下载校验、NeDB 迁移、托盘、自启动和平台打包均未实施。证书路径未读取本机文件；示例版本号和包大小不代表最新 release。TOML 暂限原型模型支持字段，HTTP/HTTPS 每条一个域名。

独立终审提出两项必要修复：小字对比度与标题前重复标签。两项均完成，最终 verdict 为 `ship`，该结论只覆盖列出的修复。浅色成功状态的文字在普通与双层选中背景上分别达到 6.53:1、6.01:1；主按钮及危险按钮默认和 hover 状态均达到 4.5:1。亮色主题保留 scoopUI 原有语义色，动作与状态文字使用独立可读性 token。
